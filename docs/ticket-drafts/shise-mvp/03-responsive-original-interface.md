## What to build

玩家在手机或桌面上能清楚选择瓶子、识别颜色和交付状态，关卡数量变化时保持最多三行。将原型的暖色工坊、方瓶和交付卡落实到可玩流程，并提供基础声音/震动设置。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T15、T16、T20。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 12 位为 6＋6；13 为 6＋6＋1；18 为 6＋6＋6；19 为 7＋7＋5；21 为 7＋7＋7；22 为 8＋8＋6；24 为 8＋8＋8。短行居中，无第四行或横向滚屏。
- [ ] 总瓶位包含恰好两个广告预留位，放在最下方至少有两个位置的一行两端；13 位时放第二行两端；收取后不压缩重排其他位置。
- [ ] 颜色有符号或编号辅助；触控和鼠标均可选中、取消并完成基本倾倒，命中区互不重叠，密集排列不遮住关键信息。
- [ ] 在基础手机宽度及较窄、较宽尺寸验证无横向溢出；8 瓶一行的可读性和点击反馈通过实际预览检查，不虚报固定触控宽度。
- [ ] 原创表现与基础音效/震动开关在可玩关卡中生效；设备不支持时保留视觉反馈。设置先在会话内生效，持久化由 [#13](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/13) 完成。
- [ ] 登记实际使用的素材/依赖来源；本期不导入参考游戏贴图或音频。
- [ ] 通过会话的设置与操作结果，以及少量浏览器布局/点击检查验收；高密度示意数据不冒充额外可玩关卡。
