## What to build

玩家可以用独立的模拟奖励开启第四个收集槽，让一个尚未分配的目标进入该槽，并继续完成收集。该奖励不影响下方广告空瓶。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T11。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 第四槽默认锁定，使用明确不同于空瓶奖励的目标身份；成功、取消和失败遵循统一请求流程。
- [ ] 只从未分配目标库存取得目标，不复制已有需求；开启槽位不增加颜色库存或直接增加收取计数。
- [ ] 没有待分配目标时不给出无实际作用的广告请求；目标耗尽和辅助槽状态不错误阻塞胜利。
- [ ] 空瓶奖励不会开放第四槽，第四槽奖励不会开放空瓶；错误目标和旧结果均不发奖。
- [ ] 玩家可完整演示开启后匹配收取、后续目标补充和胜利；覆盖奖励隔离的会话与浏览器检查。
