## What to build

玩家识别只能接水的瓶子，将其装成单色满瓶后单独解除固定，并按目标要求交付。交付 S10–S11，从单瓶教学到同行多瓶。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T02、T07。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 受限定色瓶可接收合法同色内容，但作为源倒出时被拒绝且局面不变。
- [ ] 装满一只瓶子只解除该瓶固定，同行其他未满瓶继续受限；满瓶等待目标，不立即无条件删除。
- [ ] 已完成单色满瓶按本版约定封口后不再倒出；限制、满瓶和收取是可分别观察的状态。
- [ ] 提供 S10 的单只教学和 S11 的多只同行示例，定色瓶预填已知单色，不叠加未定义的隐藏混色或封签。
- [ ] 保留免费自由空瓶与两个独立广告预留位，不能把定色瓶算成普通中转空间。
- [ ] 通过公开操作验证禁止倒出、逐瓶解除、待收与通关，检查实际底座和提示表现。
