## What to build

玩家可以启动网页版本，选择源瓶与目标，整理颜色并完成一个基础关卡。以现有沙盘为行为参考建立最小正式游戏会话入口，同时交付基础验证关卡 S01–S03；工程配置、输入、规则、界面与行为验证随这条可玩流程一起完成。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T01、T02、T04、T08、T17。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 提供可执行的启动与检查方式；从主页进入实际可玩的基础关卡，而非只显示设计稿。
- [ ] 普通瓶容量为 4；连续同色段按目标余量转移；空瓶和同顶色目标可接水，非法自倒、满目标、异色目标均不改变状态。
- [ ] 用稳定瓶位标识驱动选中、取消和倾倒；每关包含两个锁定广告空瓶预留位，暂不实现广告解锁，也不把它们作为免费空间。
- [ ] 三个基础收集槽可接收本关已明确的目标，单色满瓶没有匹配目标时等待；收取不复制颜色，必要收取完成后展示一次基础胜利。
- [ ] 提供 S01–S03 的明确局面与手工可重放解法；不使用广告帮助即可完成。后续统一求解校验由 [#11](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/11) 提供。
- [ ] 在游戏会话公开入口验证基本动作与不变性，通过浏览器完成一局；定义后续功能可复用的可见状态与动作结果契约。
