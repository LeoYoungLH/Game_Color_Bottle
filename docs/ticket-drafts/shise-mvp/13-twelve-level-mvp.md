## What to build

用户能够选择并连续游玩完整的 S01–S12 验证清单，体验全部机制与组合，并看到本版完成。整合前序已交付关卡，补齐 S12 和最终交付说明，形成可评审的 MVP。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T19。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 收齐 S01–S03 基础、S04–S05 目标、S06–S07 隐藏、S08–S09 封签、S10–S11 定色，补齐一关组合 S12；不把验证编号当成正式教学前 12 关。
- [ ] 每关恰有两个广告预留位并不替代免费空瓶；全部 12 关均能在不使用广告空瓶、第四槽、打乱或撤回的情况下回放通关。
- [ ] 记录每关的版本、种子、完整输入、轨迹与验证结果；无法验证或预算耗尽的候选不作为完成交付。
- [ ] S12 实际组合隐藏、封签、定色和目标收取；高密度排布另有边界检查，不能把未验证示意局当作额外可玩关。
- [ ] 验证清单、下一关、最后一关完成、返回主页及继续进度正常；新玩家能看到必要教学提示。
- [ ] 在最终集成版本运行类型检查、会话行为验证和关键浏览器流程；核对规格 T01–T32 的实际覆盖，区分正式实现通过项与仅计划项。
- [ ] 交付启动/检查/验收说明、素材与依赖来源和已知限制；明确真实微信广告、发布、云服务和完整 60 关仍不在本期范围。
