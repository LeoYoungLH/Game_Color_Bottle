## Acceptance criteria

- [ ] 暂停/主页入口保存最后完整提交的状态，继续时不重复执行动画对应的收取或奖励，暂停与弹窗期间背景不接受操作。
- [ ] 保存版本化的关卡身份、输入版本与种子、瓶子及可见信息、目标库存、收取数、必要历史、权益、道具机会账本、进度和设置，并验证恢复一致性。
- [ ] 重开先确认，恢复相同关卡初始内容和目标，清空规则历史；本记录已经取得的空瓶/辅助槽权益和未使用机会保留，已消费机会不复活。
- [ ] 进入新关重置该关两个广告空瓶及第四槽权益，使用新请求代次；按当前规格保留未使用道具机会，旧请求或重复恢复不重新发奖。
- [ ] 缺失存档正常开始；损坏、版本不兼容给出明确重新开始选择；存储被禁用或写入失败时保留本次内存游玩并说明不能持久保存。
- [ ] 完成关卡进度只推进一次，当前验证清单最后一关有明确完成状态；声音/震动设置恢复后生效。
- [ ] 没有合法动作时展示适用的撤回、重开与剩余广告空瓶选择；撤回仍遵循机会规则，不把暂时卡住直接判成无法继续的永久失败。
- [ ] 通过会话保存恢复契约、可控失败存储适配器，以及少量真实浏览器刷新/继续流程验收；不直接检查存储私有结构作为主要测试。
