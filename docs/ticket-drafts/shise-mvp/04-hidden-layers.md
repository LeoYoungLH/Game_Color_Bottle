## What to build

玩家能在两关中逐步显露隐藏颜色、完成收取，并区分已知与未知信息。交付 S06–S07，保证隐藏层参与正常倒水和目标结算。

依据当前《拾色工坊 MVP》规格；通过游戏会话公开入口验证玩家可见行为，并补充本票所需的少量浏览器检查。规格验收引用：T03。这些编号是验收场景，不是 GitHub Issue 编号。

## Acceptance criteria

- [ ] 开局固定颜色与各层可见信息；隐藏层不是空层，允许一个瓶子初始有多层可见颜色。
- [ ] 倒走顶层后显露新的顶层，保留已知信息；对外可见状态不泄露仍隐藏的具体颜色。
- [ ] 新显露的同色内容与已有容量、待收和目标更新规则一致，不额外赠送内容或收取次数。
- [ ] 为 S06–S07 提供可重放的无广告解法和安全显露路径说明；不要仅以全知解法证明玩家不会被迫盲猜。
- [ ] 通过公开操作观察显露前后局面，并在浏览器检查遮片与颜色符号。后续跨撤回、打乱和存档场景由对应任务集成。
