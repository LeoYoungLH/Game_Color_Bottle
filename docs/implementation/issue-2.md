# Issue #2：基础可玩流程实施记录

任务：[完成基础倒水与收取的一关可玩流程](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/2)。本记录只覆盖 D01，不将设计沙盘中的后续功能视作已实现。

## 实现

- 用 TypeScript 提供独立的游戏会话：创建关卡、读取防外部修改的可见快照、选择/取消、直接倾倒及事件结果。
- 连续同色段按目标余量转移；非法操作不改变状态，锁定广告瓶位始终不可参与。
- 三个固定交付目标，匹配的单色满瓶收取一次；没有匹配目标的满瓶留在原位置等待。已收走的瓶位不能重新当作免费空瓶。
- 提供三个基础关卡和独立手工解法，全部通过公开操作回放验证。
- 完整网页流程：主页、选关、游戏界面、交付状态、通关、重新开始和页面内返回继续。

## TDD 记录

先建立失败的公开行为测试，再实现相应功能。观察过的失败包括：缺少会话模块、缺少倾倒命令、非法操作未被拒绝、满瓶未收取、满瓶等待状态缺失、选瓶命令缺失、关卡模块缺失和非法关卡输入未被拒绝。各对应切片在实现后通过定向检查。

边界校验、类型检查和构建均以公开接口及标准工具为依据，没有直接断言私有辅助函数或内部调用次数。
