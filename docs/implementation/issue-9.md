任务：[完成独立广告解锁的第四收集槽](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/9)。沿用 Issue #8 的模拟请求与四种结果，不播放真实广告，也不增加可玩关卡数量。

## 会话行为

- 三个基础收集槽仍独立存在；第四槽以稳定 `slot-4` 身份初始锁定。会话快照单独暴露第四槽的锁定/开放、当前颜色和完成状态。
- 请求使用 `fourth-slot` 奖励类型与 `targetId`，绑定当前关卡、会话身份及唯一请求 ID。成功才从未分配目标队列取一个目标，不能复制其他槽已有的需求或改变颜色库存、直接增加收取数。无剩余目标时拒绝请求。
- 第四槽一旦开放，与基础槽按稳定槽 ID 顺序匹配单色满瓶；收取后从尚未分配目标补位。新目标匹配已满瓶时继续连锁结算。队列耗尽且所需内容收完才胜利；锁定而无用的第四槽不阻塞通关。
- 下方空瓶与第四槽奖励各自独立；错误目标/类型及旧请求结果被拒绝，取消或失败不消耗目标。
