# Issue #13: 重开、暂停与本地保存恢复

任务：[完成同一记录重开与本地恢复](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/13)。

## 会话与记录

- `restart` 是会话命令：确认后恢复固定关卡的初始瓶层、可见信息、目标和计数，清空倒水历史、选择与待处理广告，换新会话代次；已取得的广告空瓶及第四槽重新应用，未用打乱/撤回机会与反馈设置保留，已消费机会不返还。第四槽按开局目标库存分配，匹配的待收满瓶照常结算。
- `restoreGameSession` 接收未知数据，先检查版本、关卡、瓶位身份/状态、颜色库存和目标需求守恒、收取记录、封签/定色内容、历史、阶段、机会与设置，再原子恢复。恢复时不重放奖励，未完成广告作废，使用新会话身份。损坏状态抛错，不改变现有会话。
- 新关建立新会话，锁定两个广告空瓶和第四槽，仅携带未使用的道具机会与反馈设置。通关列表用关卡 ID 去重；已完成关卡可重玩，当前记录刷新后可继续或查看通关弹窗。无合法倒水时提供适用的撤回、重开和剩余广告空瓶入口，不把局面标为永久失败。
- 进行中确认“重新开始”属于同一记录，保留本关广告权益；通关后“新开本关”或从关卡列表重新选择已通关关卡属于新记录，重置该关广告瓶/第四槽，但保留未用道具机会和已完成标记。

## 本地存储

- `createGameStore(storage, levels)` 使用可注入 `getItem/setItem` 适配器，保存格式版本、关卡 ID/输入版本/种子、完整会话恢复状态和已完成关卡。读取先做结构、目录版本及一致性检查，再创建恢复会话。校验值只检查意外损坏，**不**提供防篡改保证。
- 缺失返回 `missing`；损坏返回 `corrupt`；格式或关卡版本不兼容返回 `incompatible`；浏览器存储访问/写入失败返回 `unavailable`。页面在失败时保留当前内存对局并显示无法持久保存的警告，损坏/不兼容时提供开始新记录选择。

## 验证

- 82 项测试覆盖会话重开与权益、隐藏/封签/定色/第四槽恢复后继续通关、打乱消费与历史边界、错误收集槽和提前开放受限瓶的拒绝、旧请求失效、跨关机会/设置继承，以及缺失/损坏/不兼容/禁用/配额失败的存储适配器。
- 隔离端口 5178 浏览器检查：S06 倒水显露、开启 ad-1、声音开启后刷新，主页出现“继续”，恢复后倒水数 1、显露状态、广告瓶与设置一致；确认重开后内容回到开局而 ad-1 仍开放。S01 通关刷新后显示已完成 1/11 和“查看通关”，可进入 S02 且广告瓶重新锁定。临时服务已停止，不影响原 5177 预览。
- 存储只作用于同源浏览器；本票不实现登录、云同步、跨设备存档或正式微信生命周期。校验是结构/库存/目标一致性，不证明任意手工篡改记录在规则上可达。
