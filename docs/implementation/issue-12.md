# Issue #12: 广告获得一次机会的打乱

任务：[完成广告机会打乱](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/12)。继续使用可控模拟广告结果，不播放真实广告。

## 规则与权益

- 打乱与撤回机会分别记账，各最多持有 1 次。没有符合条件的未满混色瓶时不发起无用广告；成功广告只发放机会，不改变瓶子或倒水历史。取消、失败、无可用、错误目标/类型和重复旧回调不发奖。
- 候选仅对状态为可用、含 2–3 层且至少两种颜色的瓶子做瓶内排列；优先尝试所有符合条件瓶的重排组合，再尝试不同的部分组合。只有颜色序列实际改变才算打乱，同色层显露标记互换不算有效变化。颜色与显露标记成对移动，新顶层按规则显露。容量已满瓶（含混色）、封签瓶、定色瓶、广告锁定位、空瓶与已收走瓶位不参与。
- 最多枚举 128 个组合，共享最多 800 个搜索节点，经 `checkReorderCandidate` 在当前对局完整规则下确认仍有通关路径后才提交并扣 1 次；搜索或组合上限截断返回未知，未找到可解候选或无实际变化不改局面、不扣机会。不是随机生成关卡，也不声称重排路线最短。
- 成功打乱清空此前倒水历史，保留已获的广告瓶、第四槽和撤回机会；之后新倒水仍能撤回，但不能跨越打乱回到旧局面。失败不清空历史。

## 验证

- 71 项会话测试覆盖 S03 的左下角 0→1→0、固定的四步通关回放、与撤回/空瓶/第四槽隔离、失败与旧回调、预算 0 保留机会、成功后历史边界、满瓶/封签/定色/锁定位保护、双瓶组合重排、隐藏层颜色与显露标记同移，以及同色标记交换不算打乱。
- 浏览器手工检查：S01 无对象时左下按钮禁用；S03 点击左下角，模拟加载失败后局面不变，重试“模拟成功”仅显示角标 1，下一次点击重排 B 并归零，满瓶 A/C 未变。约 355px 的本机窄屏视口五个底部按钮不重叠且无横向溢出；本机浏览器未能设到 320px，本票不声称已通过该尺寸或自动化浏览器检查。
- 真正重开/存档/跨关机会保留由后续任务接入。当前页面重开新建会话会重置广告权益，属于尚未完成的范围。
