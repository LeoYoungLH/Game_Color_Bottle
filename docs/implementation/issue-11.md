# Issue #11: 有依据的提示与关卡回放

任务：[让玩家获得有依据的提示与关卡回放结果](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/11)。

## 搜索与提示

- 游戏会话公开 `findSolution(nodeBudget, witness?)` 和 `getHint(nodeBudget, witness?)`。作者轨迹先用真实 `pour` 命令从当前状态回放至胜利，错误或不完整轨迹不能被采信。若无有效轨迹，搜索使用同一会话规则试探合法倒水；每次试探后恢复瓶子、目标、收取、隐藏层、权益及撤回历史。已收走位置、封签、定色瓶和广告锁定/开放状态均由正式结算判断。
- 搜索返回 `solved`（具体可重放路线）、`unsolvable`（状态穷尽）或 `unknown`（节点预算、256 步深度保护或广告等待）。预算耗尽不叫无解；找到的路线不保证最短。页面最多展开 800 个状态，操作仍可继续。
- 提示只返回当前可见的源顶层颜色、源/目标瓶 ID、目标为空或顶层同色的理由。仍有隐藏层或未揭封瓶时，显示“当前操作合法，不保证后续通关”；不显示后续路线或隐藏真实颜色。无可靠路线时明确告知预算不足或当前已开放瓶位无解，并保留撤回、重开与广告空瓶入口。
- 已选中提示源瓶时告知直接点目标；若选中的是另一瓶，则先取消选择，再依次点击提示的源和目标。
- 供 Issue #12 使用的 `checkReorderCandidate(nodeBudget, reorders)` 在当前会话的中途局面上临时检查未满混色瓶内部的“颜色+显露标记”排列。拒绝跨瓶增减颜色、满瓶/受限瓶、重复目标和无变化候选；按顶层规则显露后调用同一三态搜索，最后恢复原状态。该入口只检查，不执行打乱或扣机会。
