# Issue #7: 定色瓶逐瓶解除固定

任务：[完成只能接水的定色瓶与逐瓶解除固定](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/7)。本票保留原有封签瓶和普通瓶规则，不把同行限制当成整行权限。

## 行为

- 关卡配置 `receiveOnly` 的瓶子开局预填已知、未满的单色层；首期不与封签或隐藏层叠加。作为源或直接选为倒水源时拒绝，作为目标时仍按同色、容量和已收走位置规则接水。
- 本瓶装成单色满瓶时只解除该瓶固定，原瓶位不变；若此时无匹配收集槽，进入单色满瓶待收状态，仍不能再倒出。另一只定色瓶的限制不变。
- S10 单瓶先解除固定并等待目标，随后随目标补位收取；S11 的 I/K 同在第一行，先 I 后 K 分别解除。两关均保留至少两个免费空瓶和两个独立锁定的广告空瓶位，并有无广告通关轨迹。

## 验证

- 公开会话测试覆盖源拒绝且局面不变、异色目标拒绝、合法接水、逐瓶解除、无目标时待收、目标补位后收取、当前目标匹配时同一动作按倒水→解除→收取只结算一次、两个广告位保持锁定、关卡输入后续修改不影响限制，以及不合法初始定色配置的拒绝。十一关手工轨迹通过同一公开入口回放至胜利。
- 浏览器逐步检查 S10 的源拒绝提示、J→I 后底座消失且原位待收，以及后续收取；S11 中 I/K 同行、先装满 I 时 K 仍保留固定底座，再单独解除 K。手机尺寸下 11 位为 6+5 且无横向溢出。
- 公开状态保留初始 `receiveOnly` 标记和当前 `status`，供后续撤回/存档区分限制来源；玩家快照不是包含隐藏真实颜色的可信存档格式。跨撤回、存档和打乱的状态恢复不在本票声称完成。
