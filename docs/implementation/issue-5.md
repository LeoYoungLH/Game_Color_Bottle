# Issue #5: 隐藏层与显露

任务：[完成隐藏层信息与顶层显露](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/5)。承接 S01–S05，不改变容量、目标库存和收取规则。

## 实现边界

- 关卡用自底向上的零基位置声明初始隐藏层。初始顶层必须可见；下层可同时存在已知色与未知色。
- 会话内部保存确定的真实颜色及逐层显露状态。公开快照只用 `null` 表示尚未知的层，保留它占用的容量；不返回隐藏位置配置或该层的真实颜色。
- 顶层连续同色段仍按真实颜色与剩余容量倾倒。移走的层在目标瓶可见；源瓶新暴露的顶层显露一次，原来已经知道的其他层不重新遮盖。非法动作不改变显露状态。
- 页面以纸质遮片和问号显示未知层，并用提示报告新显露的瓶子和颜色；颜色仍由符号辅助。

## 安全显露路径

- **S06**：开局 A 顶部珊瑚两层、B 顶部靛蓝两层、C 顶部苔绿两层均可见，A/B 各有一层未知。先 A→D（D 空，显露 A 的苔绿），再 C→A（匹配苔绿），B→C（匹配靛蓝并显露 B 的珊瑚），最后 B→D（匹配珊瑚）。每一步的源顶层和目标容量在动作前可见。
- **S07**：A/B/C 的顶层分别为珊瑚/靛蓝/苔绿，且各有一层未知。先 A→D 显露 A 的苔绿，C→A 显露 C 的靛蓝，B→C 显露 B 的珊瑚；此后 B→D、C→B、A→C、A→D、C→A、B→C、B→D 均可依据当前已显露顶层和空位/同色目标操作。这里给出一条无广告、无需预知未知色的路径，不证明所有走法都不需要试探。
