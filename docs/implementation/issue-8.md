# Issue #8: 两只广告空瓶的模拟解锁

任务：[完成两个广告空瓶与独立模拟奖励结果](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/8)。这是可控的规则验证适配，不播放真实广告，也不接入微信 SDK。

## 会话行为

- 每关两个广告空瓶按固定 ID 占位，开局为空且锁定，免费空瓶照常存在。点击指定锁定位发起一次 `empty-bottle` 请求；请求由会话生成唯一 ID，并绑定关卡、会话身份与瓶位。
- 等待结果时普通倒水、选瓶、设置和第二个请求均被拒绝。仅完全匹配待处理请求的结果被接受；错误目标、类型、关卡、代次、ID 和重复回调不发奖、不清除合法待处理请求。
- 四种可控结果为成功、提前关闭、加载失败和无可用广告。非成功结果清除等待，不改棋盘和计数，可重新请求；成功只开放所选空瓶，另一个保持锁定，不直接增加颜色或收取数。
- 开放后空瓶按普通容量、倾倒和收取规则运行；收走的位置不再变成可用空瓶。新会话生成新身份与两个默认锁定位，旧结果无效。

## 验证与边界

- 公开会话测试覆盖等待冻结、四种结果、独立瓶位、重复/过期/跨关结果、新请求 ID、解锁后接水、倒出、收走且不补位。原有十一关无广告回放继续通过。
- 浏览器点击锁定 ad-1 打开明确标注的模拟弹窗；强制背景点击不推进对局。提前关闭、失败、无可用广告后仍锁定且可重试；Esc 等同提前关闭。成功后仅 ad-1 原位开放；实测它接水、倒出、再次接水并被收取，ad-2 保持锁定。
- 真实广告服务与权限、权益跨本关重开和持久存档、第四槽及道具奖励由后续任务接入。当前点击“再玩一次”仍创建新会话并重锁广告瓶；不能把本票误称为已完成同一记录的权益持久化。
