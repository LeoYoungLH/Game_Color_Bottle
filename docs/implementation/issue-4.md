# Issue #4: 原创界面、排布与反馈

任务：[完成原创界面与多瓶位响应式排布](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/4)。用户指出 Issue #2 的桌面卡片/侧栏界面与参考录屏差距过大；本轮按移动棋盘优先、紧凑深色高对比方向重做，不将参考游戏贴图或品牌移植进工程。早期暖白工坊草案仅作为历史设计输入，不是本轮验收后的定稿承诺。

## 实现

- 首页改为关卡选择，游戏页将进度、三个收集槽、瓶阵和操作上下排列，不再使用宽桌面侧栏。
- 原创玻璃瓶、液层与瓶位样式以 CSS 表达，颜色另有符号辅助；按钮图标仅用 Lucide Static 0.468.0（ISC），按需打包 SVG。没有导入参考游戏图像或音频。
- 5–11 位为平衡两行；12–18 位为 6+6+余数；19–21 位为 7+7+余数；22–24 位为 8+8+余数。广告空瓶按固定 ID 放在最下方容量至少 2 的一行两端，13 位时在第二行。收取后原瓶位仍保留。
- 对局会话的声音、震动开关相互独立、默认关闭。有效倒水可触发短促合成音与震动；设备禁用或拒绝时依旧显示规则结果与状态。设置尚不持久化。
- `/layout-preview.html` 为非可玩排布检视页，复用生产瓶阵组件。

## 验证

- 通过公开会话入口测试设置不改动瓶阵或步数，倒水后仍保留；已有五关轨迹继续通过。
- 浏览器在 320px 检查 5、11、12、13、18、19、21、22、24 位的行数、广告位置、按钮几何和无横向溢出；24 位最窄约 36px，不虚报 44px。390px 与桌面查看瓶层辨识和主要操作。
- 浏览器点击声音/震动开关、选瓶和倾倒，检查设置状态、选中样式、步数与提示；排布滑块从 24 切换到 13 保留交互。
- 真机触控误触、微信容器音频与震动兼容性尚未验证；浏览器检查不是发布验收。
