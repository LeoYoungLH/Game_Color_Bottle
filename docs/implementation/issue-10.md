# Issue #10: 广告获得一次机会的撤回

任务：[完成广告获得一次机会的撤回](https://github.com/LeoYoungLH/Game_Color_Bottle/issues/10)。本票继续使用可控模拟结果，不播放真实广告。

## 会话行为

- 每次成功倾倒前保存内部规则检查点，含隐藏层真实颜色及显露状态、瓶位、目标库存位置、收取记录、回合计数与胜负阶段。非法动作不进入历史。
- 没有倒水历史时不请求无效广告。撤回奖励用独立 `undo` 类型、固定目标身份、关卡/会话/请求 ID 校验；成功只给一次机会，不自动回退，上限一。取消、失败、无可用广告、错误或过期结果不发奖。
- 成功撤回消耗机会并恢复最近一次倒水及其收取、补位、揭封、定色解除、隐藏信息与胜负变化。规则历史不含机会账本；之后获得的广告瓶与第四槽权益仍有效，第四槽按恢复后的目标库存重新分配。再次点击无机会不会重复撤回。
- `getRecoveryState()` 将内部规则状态、真实隐藏层、历史和机会账本作为独立深拷贝导出，供后续存档实现使用；玩家可见的 `getSnapshot()` 仍隐藏未知颜色。本票没有导入/校验或落盘恢复入口，不能将导出数据当作可信玩家输入。
- 完成态可在弹窗申请撤回并回到进行中。左下打乱仅显示禁用占位，待 Issue #12 实现；当前不实现持久化或同一记录的重开权益继承。

## 验证

- 56 项会话测试覆盖 0→1→0、奖励隔离、失败与旧回调、组合关的收取/封签/定色/隐藏层/辅助槽逐步回退、胜利回退、解锁发生在上一步之后、恢复导出隔离以及快速重复使用。
- 可复现浏览器检查：启动服务并打开 S01；初始右下“撤回”禁用、左下“打乱”禁用。依次点击 A、D 后点击“撤回”→“模拟成功”，确认倒水计数仍为 1、右下角标为 1；再次点击“撤回”，计数回到 0、角标消失。依次点击 A→D、C→A、B→C、B→D，完成弹窗内点击“模拟广告获取撤回”→“模拟成功”→“使用撤回 1”，确认回到 2/3 收取、3 次倒水。
- 在 320×720 视口检查 `document.documentElement.scrollWidth === 320`；左下“打乱”与右下“撤回”均处于屏幕内且不重叠。上述步骤已在本地浏览器手工执行通过；尚未加入自动化浏览器测试。
