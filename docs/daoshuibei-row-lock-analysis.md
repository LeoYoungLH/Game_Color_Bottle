用户明确说明：这一行的瓶子只能接水，不能把水倒给其他瓶子，被倒满后才能解锁、收走。禁止倒出的语义来自用户直接说明；抽帧本身不证明用户所有无效点击尝试。

“被倒满”按既有同色倾倒规则与画面理解为单色满瓶。新实现将该限制记录在每个瓶子的出水权限上，行只负责展示分组。

本片已经处于第 56 关，不能据此断言第 56 关是该机制首次出现的关卡，也不能推断未展示的更后期机制。

## 与遮盖瓶的区别

- 遮盖瓶：收取数量达标才开放；解锁条件依赖其他满瓶的收取。
- 本片受限瓶：可以先接水，不能倒出；本瓶装满后解除固定。

新项目将后一种称为“定色瓶”，用固定底座和只向内箭头表示。见 [设计 V1](./design-v1.md)。

## 尚未验证的边界

- 满瓶解除固定后，原作是否允许玩家再次倒出；视频中的封口和待收状态不能证明该权限。
- 非同色、隐藏层、广告及刷新与受限瓶叠加的全部行为。
- 其他关卡受限瓶如何生成、是否有不同容量，以及是否存在其他锁定类型。

这些边界在设计 V1 中以明确建议处理，不继续要求用户先录更多视频才能完成第一版设计。
