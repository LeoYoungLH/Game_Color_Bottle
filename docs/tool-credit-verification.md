# 打乱与撤回广告次数：演示验收记录

日期：2026-11-16。对象：可点击规则沙盘。方法：通过浏览器实际按钮和瓶子操作，读取可见棋盘、次数、角标及反馈。没有新增正式游戏测试套件，也没有接入真实广告。

## 本轮已检查

| 检查 | 结果 |
| --- | --- |
| 初始左下打乱、右下撤回，次数各为 0 | 显示视频获取提示，没有数字 1 |
| 无撤回历史时点击撤回 | 不请求广告、不扣次，并显示原因 |
| 打乱广告提前关闭与加载失败 | 次数仍为 0，局面不变 |
| 完整观看打乱广告 | 仅打乱显示 1，操作前后可见棋盘文本一致，没有自动打乱 |
| 重复同一成功回调 | 明确忽略，机会仍为 1，没有变成 2 |
| 完整观看撤回广告 | 撤回显示 1，打乱已有的 1 保留；两个角标可同时显示 |
| 有 1 次时执行打乱 | A、B 的内部颜色顺序改变，打乱扣为 0；C 单色满瓶、D 混色满瓶保持原样，G 封签瓶和 I/J 广告位保持原状 |
| 打乱后立即撤回 | 旧倒水历史已清空，不执行；已获得的 1 次撤回仍保留 |
| 打乱后新倒水，再使用撤回 | 恢复刚才一次倒水，撤回扣为 0，已使用的打乱机会不复活 |
| 消费后重复旧广告成功结果 | 不重新增加已消费的机会 |
| 持有 1 次打乱，但通过倒水使所有剩余对象不再满足重排条件 | 不执行打乱，机会仍为 1 |
| 在基础场景撤回连续收取/揭封链 | 完整恢复链条并消费 1 次撤回，已解锁的广告空瓶 I 仍保持解锁，J 仍锁定 |

页面错误日志检查未出现脚本错误。

## 未由本轮演示证明的项目

- 正式存档、跨关机会持久化和重试账本尚未实现，不能以本次内存演示声称验证通过。
- 真实微信广告的生命周期和网络回调尚未接入。
- 隐藏层显露标记重排、正式打乱候选可解性筛选及预算失败回退，需要在正式实现验收。
- 自动化验收边界仍按规格草稿的待确认状态管理；本轮是用户要求的模拟验收，不替代正式测试套件。

新增的完整验收要求已进入 [MVP 规格](./specs/shise-mvp-spec.md) 的 T21–T32。对重排范围、满瓶定义、打乱后的历史边界和跨关保留采用 [设计 V1](./design-v1.md) 中明确标注的首版解释。
