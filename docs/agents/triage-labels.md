# Triage labels

工程技能使用以下五种标准角色，GitHub 标签名与角色名保持一致。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估范围、优先级和处理方式。 |
| needs-info | needs-info | 缺少必要资料，等待补充后继续处理。 |
| ready-for-agent | ready-for-agent | 需求、边界和验收条件明确，可以交给 AI 执行。 |
| ready-for-human | ready-for-human | 任务已明确，关键工作需要人工处理。 |
| wontfix | wontfix | 明确决定不处理，并在任务中记录原因。 |

这些标签用于任务分流；完成状态通常由关闭 Issue 表示。更新分流结果时移除已不适用的同类标签。

此文件定义标签映射，不代表已在 GitHub 创建标签。首次需要应用标签时，先检查远程已有标签，复用同名标签；缺失时再按授权范围创建。
