# Game Color Bottle

微信瓶子游戏的玩法研究与原创实现项目，目前处于规划阶段。

## 项目文档

- [项目术语](./CONTEXT.md)
- [研究与开发规划](./docs/wechat-bottle-game-plan.md)

目标游戏、具体玩法、开发引擎及发布范围尚待确认。当前仓库没有可运行游戏，也没有构建或测试命令。

## 开发原则

- 用可验证的行为规格描述玩法，并记录尚未确定的规则。
- 独立实现游戏逻辑，重新设计瓶子、界面、关卡及视听内容。
- 记录第三方素材与依赖的来源和许可。
- 将本机诊断、参考资料和分析产物与可发布内容分别管理。
